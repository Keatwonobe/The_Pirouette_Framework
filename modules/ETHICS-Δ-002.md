# §4 · The Resonant Frame Architecture (Applied to Call Centers)

## 4.1 The Seven-Agent Frame

From The Resonant Organization, optimal team = 7 members:

**Structure**:
```
         [Frame Interface]
               |
    [Core 1] [Core 2] [Core 3]
         |       |       |
    [Support A] [Support B]
               |
          [QA/Metrics]
```

**For Call Center**:

1. **Frame Interface** (Team Lead)
   - Manages Frame rhythm
   - Coordinates with other Frames
   - Handles escalations
   - Reports metrics
   - **D-minimization role**: Shields team from organizational turbulence

2. **Core Agents** (×3) - The Universal Agents
   - Handle customer calls across 10-15 programs
   - Build genuine relationships
   - Document edge cases
   - Mentor new agents
   - **D-minimization role**: Create coherent customer experiences

3. **Support Agents** (×2) - Research & Preparation
   - Pre-qualify leads (with AI assistance)
   - Prepare call scripts/documentation
   - Handle data entry/follow-up
   - Continuous improvement research
   - **D-minimization role**: Enable Core efficiency, reduce cognitive load

4. **QA/Metrics Specialist** (×1)
   - Track Frame metrics (calls, conversions, customer satisfaction)
   - Identify patterns (what works/doesn't)
   - Calculate Dark Residue metrics
   - Suggest improvements
   - **D-minimization role**: Measure and guide D-reduction efforts

## 4.2 Daily Rhythm (Time-Adherence Optimization)

**Morning (9-11am)**: High-energy outbound
- AI has warmed leads overnight
- Core agents receive qualified list
- Support agents monitor real-time and prepare materials
- **Peak coherence window**: Fresh minds + prepared customers

**Midday (11am-1pm)**: Inbound support + lunch rotation
- Handle inbound calls from campaigns
- Staggered 30-min lunches (Frame never fully offline)
- Light documentation catch-up
- **Maintenance phase**: Sustain momentum

**Afternoon (1-4pm)**: Mixed outbound + training
- Continue outbound on lower-priority leads
- 30-min daily training session (rotating topics across 15 programs)
- Support agents research tomorrow's targets
- **Learning phase**: Skill development

**End-of-day (4-5pm)**: Wrap-up + reflection
- Log calls, update CRM
- Quick Frame standup (10 min)
- QA/Metrics presents daily results
- Plan tomorrow
- **Feedback phase**: Close the loop

**Weekly Rhythm**:
- Monday: Plan week, review metrics
- Tuesday-Thursday: Peak performance days
- Friday: Retrospective, celebrate wins, deep-dive on one program

**Monthly Rhythm**:
- Add or remove partner programs based on performance
- Cross-Frame knowledge sharing
- Moral efficiency review
- Compensation adjustments (profit-sharing)

## 4.3 Boundary Permeability (Γ Optimization)

**Between Frames**:
- Frames operate autonomously but share learnings
- Monthly "Frame Exchange": Best practices cross-pollinate
- Agents can transfer between Frames if better fit
- **Optimal Γ**: High enough for knowledge flow, low enough for identity

**Between Company and Agents**:
- Open-book financials (agents see profit-sharing math)
- Transparent D-metrics (everyone knows the score)
- Input on which programs to add/drop
- **Optimal Γ**: Trust through transparency

**Between Company and Customers**:
- Clear pricing, no hidden fees
- Honest product limitations disclosed
- "We can't help with this" is acceptable answer
- **Optimal Γ**: Authenticity builds long-term trust

# Rank programs by D-reduction potential

**Result**: Agent feels like **helper, not seller**.
