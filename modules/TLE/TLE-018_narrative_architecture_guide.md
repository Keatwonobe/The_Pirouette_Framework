## §0 · THE CHALLENGE

**Your Goal:** Create a campaign where players organically experience a compelling narrative arc through their choices, without feeling railroaded.

**The Problem:** D&D campaigns often fail because:
- GMs force plot → players rebel → story collapses
- GMs react purely → story becomes aimless
- Story exists "around" players instead of "through" them

**The Solution:** Embed the narrative calculus into the **world systems themselves** so the story emerges from player interaction with environment, not GM intervention.

## §10 · EMBEDDING THE ALGORITHM IN GAMEPLAY

### **How To Let Players Drive Without Railroading:**

**The Handler Metric (Invisible GM Tool):**

```python
class HandlerInterest:
    """Track each PC's 'harvest readiness' invisibly"""
    
    def calculate(self, player):
        entropy = player.total_EP
        connections = len(player.NPC_bonds)
        handler_approval = player.handler_missions_completed
        
        harvest_readiness = (entropy * 0.6) + 
                           (connections * 50) +  # Bonds increase yield
                           (handler_approval * 100)
        
        if harvest_readiness > 2500:
            trigger_handler_interest()
        
        return harvest_readiness
```

**Use This To:**
- Time the harvest event dynamically
- Pressure grows naturally with player success
- Players create their own crisis timeline
- No railroad—just physics
