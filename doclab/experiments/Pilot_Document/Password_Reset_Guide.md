# Password Reset Procedure

## When to Use
Customer cannot access online banking due to forgotten password or locked account.

## Security First Approach
Frame this as: "Let's get you back into your secure account safely."

## Step-by-Step Process

### 1. Identity Verification (MANDATORY)
Verify TWO of the following:
- ✅ Date of Birth
- ✅ Last 4 digits of SSN
- ✅ Full billing address on file
- ✅ Recent transaction amount

**Script**: "To protect your account, I need to verify your identity. Can you provide your date of birth and the last 4 digits of your Social Security Number?"

### 2. Send One-Time Password (OTP)
- System automatically sends 6-digit code to registered phone
- Code expires in 10 minutes
- **Script**: "I've sent a verification code to the phone number ending in [XX]. Please read that back to me when you receive it."

### 3. Guide Through Reset
Once OTP is verified:
1. Navigate customer to: www.neobank.com/reset
2. Enter email address
3. Check email for reset link (valid 1 hour)
4. Create new password meeting requirements:
   - Minimum 12 characters
   - Mix of upper/lowercase, numbers, symbols
   - Cannot be same as last 5 passwords

### 4. Success Confirmation
- Confirm they can log in successfully
- Offer to enable 2FA (Two-Factor Authentication) for additional security
- **Script**: "Your account is now secure. Would you like me to help you set up two-factor authentication for extra protection?"

## Compliance Note
🔒 **Security Reminder**: Never share passwords, never ask customer to share their password with you, never suggest weak passwords.
