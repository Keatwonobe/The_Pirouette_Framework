## Law
Let a system's state be defined by its position in a phase space. Let its dynamics be governed by two opposing potentials: a coherence generation rate, \( K_τ \), and a pressure dissipation rate, \( V_Γ \).

The residue, \( D \), is the accumulated, uncompensated absolute difference between these potentials over time:
\[
D(t) = \int_0^t |K_τ(t') - V_Γ(t')| \, dt'
\]

Classical equilibrium is a fixed point where \( K_τ = V_Γ = 0 \). Dynamic Closure is a limit cycle, a periodic trajectory \( s(t) = s(t+τ_p) \), defined by the condition that the residue flux vanishes. The governing equation for a stable, self-sustaining system is:
\[
\frac{dD}{dt} = |K_τ - V_Γ| \to 0
\]
This implies that over any complete period \( τ_p \), the net work done is zero, and the system returns to its initial state:
\[
\oint (K_τ - V_Γ) \, dt = \int_0^{τ_p} (K_τ - V_Γ) \, dt = 0
\]
The set of all states satisfying the closure condition forms the geodesic manifold of stability, \( \mathcal{G} \):
\[
\mathcal{G} = \left\{ s \;\middle|\; \frac{d}{dt} \int |K_τ - V_Γ| \, dt' = 0 \right\}
\]
**Falsifiable Criterion:** Any system claimed to be in a state of stable, dynamic equilibrium must possess a measurable residue functional \(D\) for which it can be demonstrated that \( dD/dt \approx 0 \). If a system persists in motion yet its measurable residue flux is consistently and significantly non-zero, this model is falsified for that system.

Stability, therefore, is not a point of rest but a resonant orbit—a self-sustaining pattern of change that leaves no net residue. To endure is to master the art of the perfect return.
